# CodeX Sync

CodeX Sync is a lightweight VS Code extension that adds convenient Pull and Push buttons directly to the Source Control title bar. It serves as an internal source control management enhancement for CodeX.

## Features

- **Quick Pull**: Pull changes from the remote repository with a single click.
- **Quick Push**: Push your committed changes to the remote repository.
- **Seamless Integration**: Buttons appear right where you need them in the SCM pane.

## Configuration

You can toggle the visibility of the buttons in your VS Code settings:

- `codex-sync.showGitPull`: Enable/disable the Git Pull button.
- `codex-sync.showGitPush`: Enable/disable the Git Push button.

## Requirements

Requires the built-in VS Code Git extension to be enabled.
