# CodeX Error Lens

CodeX ErrorLens turbo-charges language diagnostic features by making diagnostics stand out more prominently, highlighting
the entire line wherever a diagnostic is generated by the language and also prints the message inline.

## Features

- **Highlight lines containing diagnostics** - Visual emphasis on problematic code
- **Append diagnostic as text to the end of the line** - See error messages directly in your code
- **Show icons in gutter** - Quick visual indicators in the editor margin
- **Show message in status bar** - Keep track of errors at a glance
- **Customizable severity levels** - Choose which diagnostic levels to display (error, warning, info, hint)
- **Rich customization options** - Control fonts, colors, spacing, and more
- **Status bar integration** - Display error counts and messages in the status bar
- **Code Lens support** - Interactive error information above your code
- **Search for problems** - Quick web search for error messages
- **Exclude patterns** - Fine-tune what gets highlighted

## Configuration

CodeX Error Lens offers extensive customization through the `codexErrorLens.*` settings:

### Basic Settings

- `codexErrorLens.enabled` - Enable/disable the extension
- `codexErrorLens.enabledDiagnosticLevels` - Choose which severity levels to show
- `codexErrorLens.messageTemplate` - Customize how error messages are displayed

### Visual Customization

- `codexErrorLens.fontFamily`, `codexErrorLens.fontSize`, `codexErrorLens.fontWeight` - Typography controls
- `codexErrorLens.margin`, `codexErrorLens.padding`, `codexErrorLens.border` - Spacing and borders
- `codexErrorLens.messageBackgroundMode` - How to highlight (line/message/none)
- `codexErrorLens.severityText` - Custom icons for different severity levels

### Status Bar

- `codexErrorLens.statusBarMessageEnabled` - Show messages in status bar
- `codexErrorLens.statusBarIconsEnabled` - Show error/warning icons in status bar
- `codexErrorLens.statusBarColorsEnabled` - Use colors in status bar

### Advanced Features

- `codexErrorLens.gutterIconsEnabled` - Show icons in the gutter
- `codexErrorLens.codeLensEnabled` - Enable Code Lens integration
- `codexErrorLens.excludePatterns` - Exclude files by glob patterns
- `codexErrorLens.transmute` - Customize decoration for specific problems

## Commands

Access CodeX Error Lens commands through the Command Palette (Ctrl+Shift+P / Cmd+Shift+P):

- `CodeX Error Lens: Toggle (Enable/Disable) Everything` - Master toggle
- `CodeX Error Lens: Toggle Errors/Warnings/Info/Hint` - Individual severity controls
- `CodeX Error Lens: Toggle Inline Message` - Show/hide inline messages
- `CodeX Error Lens: Search for problem` - Web search for current error
- `CodeX Error Lens: Select Problem` - Jump to problem location
- `CodeX Error Lens: Copy Problem Message` - Copy error to clipboard
- `CodeX Error Lens: Disable Line` - Add linter disable comment
- `CodeX Error Lens: Find Linter Rule Definition` - Jump to rule configuration

## Message Template

Customize error display using variables:
- `$message` - Diagnostic message text
- `$severity` - Severity icon from `codexErrorLens.severityText`
- `$source` - Diagnostic source (e.g., "eslint", "typescript")
- `$code` - Diagnostic code
- `$count` - Number of diagnostics on the line

Example template: `[$severity] $message ($source)`

## Exclusion Patterns

Fine-tune what gets highlighted:

```json
{
  "codexErrorLens.excludeBySource": ["eslint", "typescript"],
  "codexErrorLens.excludeByMessage": ["TODO", "FIXME"],
  "codexErrorLens.excludePatterns": ["**/*.test.ts", "**/node_modules/**"]
}
```

## Status Bar Integration

The status bar can show:
- Error and warning counts with customizable icons
- Current error message at cursor position
- Clickable actions (go to problem, copy message, etc.)

## Code Lens

When enabled, CodeX Error Lens adds interactive Code Lens items above problematic code, providing quick access to common actions like searching for solutions or viewing quick fixes.

## Performance

CodeX ErrorLens is optimized for performance:
- Debounced updates to reduce UI thrashing
- Configurable delays before showing decorations
- Efficient diagnostic processing
- Minimal impact on editor responsiveness
